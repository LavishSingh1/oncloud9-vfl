Honest reporting

        
The label-leakage attack is inference by an authorised party on the gradients it legitimately receives. Mutual TLS does not prevent it. An attack AUC above 0.6 is reported as succeeded. Formal ε-label-DP (randomized response) is the only setting that bounds it: it covers the trained model and the gradients passives receive, not the test metrics shown here (true labels).
